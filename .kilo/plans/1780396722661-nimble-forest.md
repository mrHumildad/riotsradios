# Email Outreach Plan for Radio Stations

## Goal
Create bilingual (Spanish/English) email templates to contact each radio station in the platform, informing them about RIOTSRADIOS, requesting data verification, and inviting them to host EPG data.

## Station Data Summary
- **Total stations**: 29 radios from stations.csv
- **Known contacts**: 2 stations have email addresses
  - Radio Contrabanda: contrabanda@contrabanda.org
  - Ké Huelga Radio: kehuelga@kehuelga.net
- **Stations without contact**: 27 stations need outreach via website contact forms

The EPG Maker produces JSON files with:
- Station metadata (name, id, timezone, contact)
- Shows dictionary with titles, categories, URLs
- Weekly schedules with start/end times and live flags
- Template available at `dist/EPGs/template.json`

## Email Template Structure

### Subject Line
```
RIOTSRADIOS - Free community radio platform / Plataforma libre de radio comunitaria
```

### HTML Email Design
- Dark background with amber/red accents
- Monospace/stencil typography
- RIOTSRADIOS header with glitch aesthetic styling
- Clean, readable format for data verification table
- EPG Maker instructions section

### Content Sections (per station)

#### 1. Spanish Intro
```
Estimado/a equipo de {{station_name}}:

Me llamo mrHumildad y estoy desarrollando RIOTSRADIOS, una plataforma libre y anticapitalista para escuchar emisoras comunitarias. Tu radio ya está incluida en el proyecto como punto de referencia para la comunidad radiopunk.
```

#### 2. Data Verification Request
```
DATOS ACTUALES (por favor verifique y corrija si es necesario):

- Nombre: {{station_name}}
- Ubicación: {{location}}
- Página web: {{webpage}}
- Stream URL: {{url}}
- Icono actual: {{icon}}

¿Alguno de estos datos necesita actualización?
```

#### 3. EPG Maker Invitation (Spanish)
```
TE INVITO A USAR EPG_MAKER:

He creado una herramienta sencilla (EPG Maker) para generar guías de programación. Los pasos son:

1. Visita: mrhumildad.github.io/epg_maker/
2. Completa la programación semanal (horarios, programas, presentadores)
3. Descarga el archivo JSON
4. Súbelo a tu web (ej: tuweb.org/epg.json)
5. Envíame la URL para incluirla en RIOTSRADIOS

Así los oyentes ven qué programa están escuchando en tiempo real.
```

#### 4. English Version
Similar structure with English translations.
