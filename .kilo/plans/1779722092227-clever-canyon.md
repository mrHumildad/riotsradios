# Header Brand Morph: RIOTS ↔ RADIOS (smooth AD insert + T collapse)

## Goal
Replace the current static multi-letter "RIOTSRADIOS" header title with a looping smooth animation:
- "RIOTS" (visible: R I O T S)
- smoothly appears "AD" between R and I **while** T collapses
- reaches "RADIOS" (visible: R A D I O S)
- hold
- reverse animations (AD collapses, T expands)
- back to "RIOTS"
- loop forever

Incorporate user-specified preferences from planning Q&A:
- 4.5 s hold per word, ~1.1 s morph each direction
- Reduced-motion: lock to static classic "RIOTSRADIOS" (original 11 letters, all anims disabled)
- A11y: add visually-hidden current word inside the h1
- T collapse: include quick color flash / blur effect **during** the morph
- Glitch animations: keep running at all times (no pausing)

## Project Context
- Single-file React entry: `App.jsx` (React 19, Vite)
- All styles: `styles.css` (one file, custom properties + many existing infinite keyframe glitches + brand glow)
- Header lives at `App.jsx:74` inside `.chassis-header`
- Current brand markup: `App.jsx:85-97` (h1.header-brand with 11 individually classed spans + data-text="RIOTSRadIOS")
- Existing CSS blocks (lines ~168-404): .header-brand, per-letter riot/ad styles, ::before/::after text layers, brand-warm-glow, letter-bridge for the -6 R
- No external animation libs, no lint script (`npm run build` is the verification command)
- Strict coding rule: **never add any source comments** (`//` or `/* */`) in edits
- .header-brand is `display:flex; gap:1px; justify-content:center; position:relative;`
- Font: var(--font-display) = "Abril Fatface"

## High-Level Solution
- Add React state + timer-driven 4-phase cycle in App (honors 4.5s / 1.1s)
- Conditionally render either the new 7-element morph markup **or** the original 11-element static markup (based on `prefers-reduced-motion`)
- Drive the insert/collapse purely via CSS `max-width + overflow:hidden` (on a lightweight `.ad-cluster` wrapper + on `.header-brand-t`) + `transform: scale` / `opacity` + a short flash keyframe on T
- Keep 100% of existing glitch keyframes / colors / glows (they become "legacy only for reduced-motion fallback")
- Add minimal new CSS (no comments) for `.ad-cluster`, `.header-brand-t` transitions, flash, visually-hidden, and the reduced-motion media query overrides
- Update only the h1 JSX + add one small useEffect + one useState for reduced detection + cycle logic
- Result: zero new comments, minimal diff outside the morph feature, fully honors user answers

## Detailed Implementation Steps

### Step 1: App.jsx – state, detection, cycle, and conditional markup (no comments)

1. After the existing `const [epgModalStation, setEpgModalStation] = useState(null)` add exactly two new state lines:
   ```js
   const [brandState, setBrandState] = useState('riots');
   const [brandWord, setBrandWord] = useState('RIOTS');
   ```
   (plus a reduced-motion detector – see below)

2. Add a new `useEffect` (place it immediately after the keyboard useEffect, before the `return (`) that:
   - Uses `window.matchMedia('(prefers-reduced-motion: reduce)')` to set a `prefersReduced` state (with change listener + cleanup)
   - If `prefersReduced`, do nothing (no timers)
   - Otherwise start a 4-phase recursive timeout cycle using the exact timings:
     - phase 0 (riots): 4500 ms hold → set 'riots' + 'RIOTS'
     - phase 1 (morph forward): 1100 ms → set 'radios' + 'RADIOS' + temporary 'is-morphing' class for 650 ms
     - phase 2 (radios): 4500 ms hold
     - phase 3 (morph reverse): 1100 ms → set 'riots' + 'RIOTS' + temporary 'is-morphing' for 650 ms
     - loop
   - Proper cleanup of the active timeout on unmount or when reduced changes
   - Use a single `let timer` + `clearTimeout` pattern (no arrays of timers)

3. Update the `<h1>` (was line 85) to:
   ```jsx
   <h1
     className={`header-brand ${brandState}${prefersReduced ? ' reduced-motion' : ''}${isMorphing ? ' is-morphing' : ''}`}
     data-text={brandWord}
     aria-label="RIOTSRADIOS"
   >
     <span className="visually-hidden">{brandWord}</span>
     {prefersReduced ? (
       // original 11 spans – exact copy of today's markup
       <>
         <span className="header-brand-r">R</span>
         <span className="header-brand-i">I</span>
         <span className="header-brand-o">O</span>
         <span className="header-brand-t">T</span>
         <span className="header-brand-s">S</span>
         <span className="header-brand-6">R</span>
         <span className="header-brand-a">A</span>
         <span className="header-brand-d">D</span>
         <span className="header-brand-i2">I</span>
         <span className="header-brand-o2">O</span>
         <span className="header-brand-s2">S</span>
       </>
     ) : (
       <>
         <span className="header-brand-r">R</span>
         <span className="ad-cluster">
           <span className="header-brand-a">A</span>
           <span className="header-brand-d">D</span>
         </span>
         <span className="header-brand-i">I</span>
         <span className="header-brand-o">O</span>
         <span className="header-brand-t">T</span>
         <span className="header-brand-s">S</span>
       </>
     )}
   </h1>
   ```
   - Also add a tiny `const [isMorphing, setIsMorphing] = useState(false);` (or derive it inside the cycle without extra state if possible – one extra state is acceptable)

4. The cycle logic must also manage the short-lived `isMorphing` flag (set true for ~650 ms exactly when we start a morph phase, then auto-clear). This drives the T flash keyframe.

No other changes to App.jsx (no new imports, no comments).

### Step 2: styles.css – additions only (zero deletions, zero comments)

Add the following blocks **at the very end of the file** (after the last existing rule). All added CSS must contain **zero comments**.

```css
.visually-hidden{position:absolute;width:1px;height:1px;padding:0;margin:-1px;overflow:hidden;clip:rect(0,0,0,0);white-space:nowrap;border:0}

.ad-cluster{display:flex;align-items:center;gap:1px;max-width:0;overflow:hidden;transition:max-width 1100ms cubic-bezier(.25,.1,.25,1),opacity .7s ease}
.header-brand.radios .ad-cluster{max-width:1.72em}

.header-brand-a,.header-brand-d{transition:transform .65s ease,opacity .5s ease;transform:scale(.38);opacity:.35}
.header-brand.radios .header-brand-a,.header-brand.radios .header-brand-d{transform:scale(1);opacity:1}

.header-brand-t{display:inline-block;max-width:.71em;overflow:hidden;transition:max-width 1100ms cubic-bezier(.25,.1,.25,1),transform 1100ms ease,opacity .75s ease;transform-origin:center}
.header-brand.radios .header-brand-t{max-width:0;transform:scaleX(.11);opacity:0}

.header-brand.is-morphing .header-brand-t{animation:t-morph-flash .55s cubic-bezier(.4,0,.2,1) 1}
@keyframes t-morph-flash{0%,100%{filter:none;color:inherit}35%{filter:blur(.9px) saturate(1.4);color:#ff2e2e}}

@media (prefers-reduced-motion:reduce){
  .header-brand,.header-brand *{animation:none!important;transition:none!important}
  .header-brand.reduced-motion>span,
  .header-brand.reduced-motion .header-brand-6,
  .header-brand.reduced-motion .ad-cluster,
  .header-brand.reduced-motion .header-brand-t{opacity:1!important;transform:none!important;max-width:none!important}
  .header-brand.reduced-motion .visually-hidden{display:none}
}
```

(The 1.72em / .71em values are starting points; the implementer will visually tune them by 0.05–0.1 em steps in the browser until "AD" fully appears without clipping and T fully collapses cleanly.)

The existing 11 letter selectors, their colors, their @keyframes (letter-riot-*, letter-ad-*, letter-bridge, brand-warm-glow, glitch-rim, glitch-jitter) and the two ::before/::after rules are left completely untouched. They only become active when the original 11 spans are rendered under `.reduced-motion`.

`.header-brand` already has `position:relative` (line 180), so the visually-hidden and any future absolute children work.
