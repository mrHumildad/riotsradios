# Splash Screen Plan

## Goal
Add a splash screen that displays `public/logo_flicker_loop.gif` for 5 seconds on app load, then fades away — no React Router used.

## Project Context
- Vite + React 19 SPA, served at base `/onlypunks/` (vite.config.js)
- React Router is **not installed or used**
- GIF asset already exists: `public/logo_flicker_loop.gif`
- Entry points: `index.html` → `main.jsx` → `App.jsx`
- CSS is in `styles.css`, no CSS modules
- `#root` in `index.html` is the React mount point

## Approach

### 1. `index.html` — Inject splash overlay markup
Add a `<div id="splash">` with an `<img>` for the GIF, inserted in `<body>` **before** `<div id="root">`.

```html
<body>
  <div id="splash">
    <img src="/logo_flicker_loop.gif" alt="RIOTSRADIOS" class="splash-gif" />
  </div>
  <div id="root"></div>
  <script type="module" src="/main.jsx"></script>
</body>
```

### 2. `styles.css` — Add splash screen styles

Add splash overlay class:

```css
/* ---- SPLASH SCREEN ---- */
#splash {
  position: fixed;
  inset: 0;
  z-index: 999999;
  background: #0a0a0a;
  display: flex;
  align-items: center;
  justify-content: center;
  animation: splash-out 5s linear forwards;
}

#splash .splash-gif {
  width: min(300px, 80vw);
  height: auto;
  max-width: 80vw;
  display: block;
}

@keyframes splash-out {
  0%, 88% {
    opacity: 1;
    visibility: visible;
  }
  100% {
    opacity: 0;
    visibility: hidden;
  }
}
```

### Why no React/JS hidden class toggle?
- Pure HTML + CSS `animation: splash-out 5s forwards` applied directly to the `#splash` element gives an exact 5s lifecycle with zero branching, no HOC, no mount/unmount, no Router integration.
- Works standalone — the overlay hides itself from page load regardless of React hydration timing.
- Does not block `main.jsx` / React hydration; the fade happens on the DOM layer above React.

### 3. Considerations
- The GIF must be reused from `public/logo_flicker_loop.gif`, not loaded from the `dist/` processed assets.
- The `z-index: 999999` keeps it above the existing `body::after vignette` overlay (`z-index: 9999`).
- The `visibility: hidden` at the end ensures the splash div does not capture pointer events after fading.
- No changes to `main.jsx`, `App.jsx`, or `vite.config.js` required.
