# Filter stream_broken stations

## Goal
Filter out stations where `stream_broken` column is set to `true` in stations.csv.

## Analysis
- `stations.csv` has a `stream_broken` column with values `true` for 5 stations (Radio Malva, Ké Huelga Radio, Radio Libertaire, Radio Utopía)
- `stations.js` parses the CSV and exports the `stations` array
- `App.jsx` imports `stations` and passes them to `StationList`
- `logic.js` uses `stations` for navigation (next/prev) and EPG fetching

## Implementation Plan

### 1. Modify `stations.js`
Add a filter after parsing to exclude stations where `stream_broken` is truthy:

```javascript
export const stations = parseCsv(csvRaw).filter(s => !s.stream_broken)
```

This is the cleanest approach because:
- It filters at the data source, keeping the rest of the codebase unchanged
- Stations with broken streams won't appear in the list, won't be navigable via next/prev, and won't have EPG fetched for them
- It preserves the original CSV data while only exposing working stations
