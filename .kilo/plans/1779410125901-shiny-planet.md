# Plan: Make Sound Bars Responsive to the Live Audio Stream

## Current State
The sound bar spectrum visualizer in `comp/PlayerDashboard.jsx` (`useSoundBars` hook) is purely **simulated** — it generates random peaks driven only by volume, using `setInterval(50ms)`. Bars are completely disconnected from the actual audio stream.

## Root Cause
- `useSoundBars` has no access to the `<audio>` element that plays the radio stream
- No `AudioContext` / `AnalyserNode` is used, so there is zero frequency-domain data
- The 24 bars are randomized independently; switching stations has no effect on the visualizer's output pattern

## Desired Outcome
The 24 spectrum bars must reflect **actual real-time frequency data** from the playing audio stream, using the Web Audio API.

### 3. `comp/PlayerDashboard.jsx` — Replace `useSoundBars` with real audio analysis

Replace the entire `useSoundBars` hook and `SoundBar` component with:

#### A. `useAudioBars` hook (new)

```jsx
function useAudioBars(audioRef, isPlaying, volume) {
  const [bars, setBars] = useState(Array(24).fill(0));

  useEffect(() => {
    if (!isPlaying) {
      setBars(Array(24).fill(0));
      return;
    }

    let audioElement = audioRef.current;
    if (!audioElement) return;

    // ── Set up Web Audio API graph ──────────────────────────
    const AudioContextClass = window.AudioContext || window.webkitAudioContext;
    const ctx = new AudioContextClass();
    const analyser = ctx.createAnalyser();
    analyser.fftSize = 512;              // 256 frequency bins
    analyser.smoothingTimeConstant = 0.82;
    const source = ctx.createMediaElementSource(audioElement);
    source.connect(analyser);
    analyser.connect(ctx.destination);    // audio still plays through speakers

    const BUFFER = new Uint8Array(analyser.frequencyBinCount); // 256 slots

    const NUM_BARS = 24;
    // Group frequency bins into NUM_BARS ranges.
    // Low-mid spectrum lives in the first ~40% of bins (bass/high-pass
    // roll-off of MP3 streams means upper bins are often empty).
    const BIN_GROUPS = [];
    for (let i = 0; i < NUM_BARS; i++) {
      const frac = i / (NUM_BARS - 1);
      // 0 → 0, 1 → 0.42 so we cover the musically-useful range
      const startFrac = frac * 0.42;
      const endFrac   = frac < (NUM_BARS - 1) / (NUM_BARS - 1)
        ? (i + 1) / (NUM_BARS - 1) * 0.42
        : 1.0;
      BIN_GROUPS.push({
        start: Math.floor(startFrac * BUFFER.length),
        end:   Math.floor(endFrac   * BUFFER.length),
      });
    }

    const MAX_VALUE = 255;

    const tick = () => {
      analyser.getByteFrequencyData(BUFFER);
      setBars(prev => prev.map((_val, i) => {
        const { start, end } = BIN_GROUPS[i];
        let sum = 0;
        for (let b = start; b < end; b++) sum += BUFFER[b];
        const avg = sum / Math.max(1, end - start);
        // Only scale when music is actually present; otherwise let the
        // AMPLITUDE_BOOST carry the bars gently.
        return Math.min(1, (avg / MAX_VALUE) * AMPLITUDE_BOOST);
      }));
      rafId = requestAnimationFrame(tick);
    };

    let rafId = requestAnimationFrame(tick);

    return () => {
      cancelAnimationFrame(rafId);
      source.disconnect();
      analyser.disconnect();
      ctx.suspend().catch(() => {});
    };
  }, [audioRef, isPlaying]);          // re-setup on station change

  return bars;
}
```

#### C. Remove random-tick cadence

Delete the 50ms threshold / `lastTick` random-sampling logic. The `requestAnimationFrame` loop drives updates at ~60fps directly from the `AnalyserNode`.

#### D. Remove `SoundBar` `isBass` / `isMid` / `isHigh`

The colour now reflects actual measured level; `isHot` (level > 0.85) is the only meaningful boolean. The colour of each bar segment (`seg-base`, `seg-mid`, `seg-warm`, `seg-hot`) is decided purely by pixel position (`segIdx`) within the bar.

#### E. Cross-fade smooth after station change cancelled

When `isPlaying` transitions from `true → false` the analyser node is garbage-collected. To avoid the instant colour-strip flash of the first analyser frame arriving mid-cleanup, the return-stub state `Array(24).fill(0)` is set *before* cleanup. No additional code needed — the prior `useEffect` return path already handles this.
