# Plan: Unify Play/Stop into a Single Toggle Button

## Goal
Replace the two separate "Play/Pause" + "Stop" buttons with a single button whose
icon, label and colour reflect the current app state — play/pause when a station is
selected, and there is no separate "Stop" button at all.

---

## App State Map

| `currentStationIndex` | `isPlaying` | Meaning                  | Button shows        |
|---|---|---|---|
| `null`               | `false`      | Idle — nothing selected | ▶ Play (disabled)   |
| non-null             | `false`      | Station loaded, stopped | ▶ Play              |
| non-null             | `true`       | Live playing            | ⏸ Pause             |

The spectrum label (`PlayerDashboard.jsx:101`) currently shows `LIVE` / `STANDBY`.
The idle case (`STANDBY`) will be split into `IDLE` and `STOPPED` to accurately
reflect the app state.

---

## Changes

### 1. `App.jsx`
- Remove `onStopRadio={stopRadio}` from the `<PlayerDashboard>` props.
- `stopRadio` is no longer destructured from `useRadioLogic()`.
- Pass `currentStationIndex` to `PlayerDashboard` as a new prop (needed for the
  three-way spectrum label).

### 2. `logic.js`
- No changes to any logic functions (`selectStation`, `togglePlay`, `changeVolume`).
- `stopRadio` stays defined in the hook but is **not** included in the returned
  object. Nothing breaks internally because the destructured array used by
  `App.jsx` will no longer pull it out.
- Return object drops `setCurrentStationIndex`, `setIsPlaying`, `setStopRadio`,
  `setCurrentStationName`, `setVolume` — only the behaviour callbacks and read
  state are kept.

### 3. `PlayerDashboard.jsx`
- **Accept new prop** `currentStationIndex`.
- **Remove the Stop `<button>`** block (lines 145–152) and the `onStopRadio` prop.
- **Update the unified Play/Pause button:**
  - `id="play-pause-btn"` remains.
  - Conditional SVG stays: play triangle when `!isPlaying`, pause bars when `isPlaying`.
  - `aria-label` is dynamic: `"Play"`, `"Pause"`, or `"Play (no station — select one first)"`.
  - `disabled` when `currentStationIndex === null`.
  - `onClick={onTogglePlay}` — single handler covers play, resume, and pause.
- **Update spectrum mode label** (line 101):
  - `"IDLE"` when `currentStationIndex === null`.
  - `"LIVE"` when `isPlaying`.
  - `"STOPPED"` when a station is loaded but `!isPlaying`.

### 4. `styles.css`
- **Remove the `.push-btn.stop-btn` rule block** (`styles.css:600-613`) — the red
  stop button is gone, this band of styles is dead code.
- No other selectors reference `.stop-btn`, so removing that block is sufficient.

### 5. `StationItem.jsx` / `StationList.jsx`
- No changes needed. The green `playing` highlight still maps to
  `currentStationIndex === index`.
