# EPG Feature Implementation Plan

## Context
- React + Vite app, no TypeScript, no UI library — vanilla React with CSS
- EPG files stored in `/EPGs/{station_id}.json`
- One example file exists: `EPGs/1.json` (Radio Contrabanda, station id=1)
- `stations.js` already has an empty `epg: ""` field on each station (unused so far)
- User wants: when a station has an EPG file, show the current show info in the station button

## EPG JSON Structure Assessment
The existing `EPGs/1.json` structure is good:
- `station_id`, `schedule_type`, `timezone`, `metadata.block_unit_minutes` (30min per block)
- `days[]` → each with `day`, `label`, `programs[]`
- Each program: `start` (HH:MM), `title`, `category`, `duration_blocks`, `live` (bool), `url` (optional), `frequency` (optional, e.g. "biweekly")
- `metadata.categories` maps category keys to display labels

**No changes needed to the JSON structure.**

## Architecture

### 1. EPG Data Loading (`logic.js`)
- Add a `useState` for `epgData` (Map from station_id → parsed JSON)
- On mount, attempt to fetch `/EPGs/{id}.json` for every station that has a non-empty `epg` field OR simply try all station ids (1..N) — since files are static, use dynamic `fetch()` with `.catch()` to skip missing files
- Store loaded EPG data in state: `Map<station_id, epgJson>`
- Expose `epgData` from `useRadioLogic()`

### 2. Current Show Computation (`logic.js`)
- Add a helper `getCurrentShow(epgJson, timezone)` that:
  1. Gets current day-of-week and time in the EPG's timezone (use `Intl.DateTimeFormat` with `timeZone` option)
  2. Finds the matching day entry in `epgJson.days`
  3. Converts each program's `start` to minutes-since-midnight, computes `end = start + duration_blocks * block_unit_minutes`
  4. Returns the program where current time falls within `[start, end)`, or `null`
- Memoize per station via `useMemo` keyed on `epgData` and a periodic time refresh (e.g. update every 60s)

### 3. Station Button EPG Display (`StationItem.jsx`)
- Accept new prop: `currentShow` (object or null), `hasEpg` (bool)
- When `currentShow` exists, alternate the station name and show title:
  - Use a CSS animation or interval to toggle between station name and show title every ~3-4 seconds
  - Station name shows normally; show title displays as `{live indicator} {title}` — e.g. `● Niemandsland` for live shows, `▷ El Acratador` for podcasts/rebroadcasts
  - Use the category to style: live shows get red-live color, podcasts get amber, rebroadcasts get dim
  - Small font, truncated with ellipsis
- Add a small amber "EPG" text pill badge in the station-aside area when `hasEpg` is true

### 4. EPG Indicator in Station List
- In `StationList.jsx`, pass `epgData` and `currentShows` down to each `StationItem`
- StationItem shows a subtle "has EPG" marker (small amber dot or "EPG" label in the aside area)

### 5. Time Update Mechanism
- Add a `useEffect` with `setInterval` (60s) that bumps a `tick` state variable
- Use this as a dependency for the `useMemo` that computes current shows, so the display refreshes every minute

## Files to Modify

1. **`logic.js`** — Add EPG fetching, current-show computation, time tick
2. **`comp/StationItem.jsx`** — Add current show display + EPG badge
3. **`comp/StationList.jsx`** — Pass EPG data/shows to StationItem
4. **`App.jsx`** — Wire epgData and currentShows from useRadioLogic to StationList
5. **`styles.css`** — Add styles for EPG show line, live indicator, EPG badge

## Detailed Changes

### `logic.js`
```
- Add: const [epgData, setEpgData] = useState(new Map())
- Add: const [timeTick, setTimeTick] = useState(0)
- Add: useEffect with setInterval(() => setTimeTick(t => t+1), 60000)
- Add: useEffect to fetch EPG files on mount:
    stations.forEach(s => {
      if (!s.id) return
      fetch(`/EPGs/${s.id}.json`)
        .then(r => r.ok ? r.json() : Promise.reject())
        .then(json => setEpgData(prev => new Map(prev).set(s.id, json)))
        .catch(() => {})
    })
- Add: const currentShows = useMemo(() => { ... }, [epgData, timeTick])
    For each entry in epgData, compute current show
    Returns Map<station_id, { title, category, live } | null>
- Expose: epgData, currentShows in return value
```

### `comp/StationItem.jsx`
```
- New props: currentShow (object|null), hasEpg (bool)
- When currentShow exists, alternate display between station name and show title:
  - Use useState + setInterval (~3.5s) to toggle a `showEpgName` boolean
  - When showEpgName=true: show `▷ {title}` or `● {title}` (live) in place of station name
  - When showEpgName=false: show normal station name
  - Wrap in a container with fixed height to prevent layout shift
- Add EPG badge in station-aside:
    {hasEpg && <span className="epg-badge">EPG</span>}
```

### `comp/StationList.jsx`
```
- New props: epgData (Map), currentShows (Map)
- Pass to StationItem:
    hasEpg={epgData.has(station.id)}
    currentShow={currentShows.get(station.id) || null}
```

### `App.jsx`
```
- Destructure epgData, currentShows from useRadioLogic()
- Pass to StationList: epgData={epgData} currentShows={currentShows}
```

### `styles.css`
```
- .station-name-container: fixed-height wrapper to prevent layout shift during alternation
- .station-name-text / .station-show-text: positioned for crossfade or swap
- .epg-live-dot: red-live colored dot for live shows
- .epg-badge: small amber pill badge in station-aside
- .station-show-text: styled per category (live=red-live, podcast=amber, rebroadcast=dim)
```
