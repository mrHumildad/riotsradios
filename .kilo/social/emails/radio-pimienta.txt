EPG MAKER INVITATION:
---------------------
I've created a simple tool to generate program guides. The steps:

1. Visit: https://mrhumildad.github.io/epg_maker/
2. Fill in weekly schedule (times, shows, hosts)
3. Download the JSON file
4. Host it on your website (e.g., tuweb.org/epg.json)
5. Send me the URL to include in RIOTSRADIOS

This way listeners see what program they're listening to in real time.
