TE INVITO A USAR EPG_MAKER

He creado una herramienta sencilla para generar guías de programación. Los pasos son:

  1. Visita: mrhumildad.github.io/epg_maker/
  2. Completa la programación semanal (horarios, programas, presentadores)
  3. Descarga el archivo JSON
  4. Súbelo a tu web (ej: tuweb.org/epg.json)
  5. Envíame la URL para incluirla en RIOTSRADIOS

EPG MAKER INVITATION

I've created a simple tool to generate program guides. The steps:

  1. Visit: mrhumildad.github.io/epg_maker/
  2. Fill in weekly schedule (times, shows, hosts)
  3. Download the JSON file
  4. Host it on your website (e.g., tuweb.org/epg.json)
  5. Send me the URL to include in RIOTSRADIOS

This way listeners see what program they're listening to in real time.
