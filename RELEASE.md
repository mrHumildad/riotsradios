# Release notes — RIOTSRADIOS

Copy-paste "What's new" text, newest first. CHANGELOG.md is the technical log;

## v1.3.0 — 2026-11-09

**en-US**

```
- New: long station names, programme titles and now-playing titles scroll instead of being cut off
- New: each channel row cycles between the station, the programme on air and the track playing
- Fixed: the footer is no longer clipped on shorter screens
- Larger text that follows your device's own font size setting
- Phones hold portrait; the navigation bar hides until you swipe up
```
