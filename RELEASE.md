# Release notes — RIOTSRADIOS

Copy-paste "What's new" text, newest first. CHANGELOG.md is the technical log;
this file is only what listeners read.

## v1.5.0 — 2026-11-12

**en-US**

```
- New: the EPG button now cycles between the channel list, the two-hour guide and the newest posts from every station
- New: a station's info opens its news log with the posts published on that feed
- New: when a newer release is available, the app offers the update
- New: the next/previous buttons on wired or Bluetooth headphones change station
```

## v1.4.0 — 2026-11-10

**en-US**

```
- New: the EPG button turns channel rows into a two-hour guide with the current time in the middle
- New: the LANG button filters the channel list by the language you hear
- New: 192 Radio Veronica, Tukker FM, Muziekknallers, Tiri 2, Tilos Rádió, Radio Seagull, SlaveFM, AccentFM, Echtepiraten.nl, Voice of Chongro and Epic Factory Underground
- Catalan and Basque channels are now tagged as such
```

## v1.3.0 — 2026-11-09

**en-US**

```
- New: long station names, programme titles and now-playing titles scroll instead of being cut off
- New: each channel row cycles between the station, the programme on air and the track playing
- Fixed: the footer is no longer clipped on shorter screens
- Larger text that follows your device's own font size setting
- Phones hold portrait; the navigation bar hides until you swipe up
```

## v1.2.0 — 2026-11-07

**en-US**

```
- New: nine stations return, including Radio Caroline, Irola Irratia, Espika FM and AppRadio
- New: Mochileros is back on a new stream after a long silence
- New: La 5ta Pata and Radio Saint Germain carry the HTTP ONLY badge and play in fewer places
```
